# Contributing to SureForgeTech projects

Thank you for helping. This page is the default for every public SureForgeTech
repository. A repository with its own `CONTRIBUTING.md` uses that file instead,
and its rules win.

## Before you start

- **Bugs:** open an issue in the repository with the version, what you did,
  what you expected and what happened.
- **Larger changes:** open an issue first so the approach can be agreed before
  you spend time on it.
- **Security problems:** do not open a public issue. See
  [SECURITY.md](SECURITY.md).

## Pull requests

- Keep each pull request to one change, and describe what it changes and why.
- Run the repository's own checks before you push (its README or
  `CONTRIBUTING.md` names them), and add or update tests for behaviour you change.
- Never commit secrets, tokens, real customer data or personal information.
  Public repositories have secret scanning with push protection enabled.
- Pull requests are squash-merged once review is complete and the required
  checks pass.
