# SureForgeTech organization profile

This repository publishes the public profile shown on the SureForgeTech GitHub organization page.

Edit [`profile/README.md`](profile/README.md) to update the profile and product catalog.

It also holds the organization's default community health files, which GitHub
shows for any repository in the organization that has none of its own:
[`CONTRIBUTING.md`](CONTRIBUTING.md), [`SECURITY.md`](SECURITY.md) and
[`SUPPORT.md`](SUPPORT.md), and the issue forms in
[`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) (a bug report, an idea, and
always a blank issue). A repository with its own issue templates uses those
instead.
