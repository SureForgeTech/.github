# Getting help

- **Questions and bugs:** open an issue in the repository concerned.
- **Security problems:** follow
  [the organization security policy](https://github.com/SureForgeTech/.github/blob/main/SECURITY.md)
  (or the repository's own `SECURITY.md`); do not post them publicly.
- **Products and documentation:** [sureforgetech.com](https://sureforgetech.com) and
  [sureforgetech.com/docs](https://sureforgetech.com/docs/).

A dedicated support channel is not yet available, and no response-time
commitment is currently stated.
